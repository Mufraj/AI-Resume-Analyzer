# AI Resume Analyzer & ATS Matching System

An AI-powered Resume Analyzer built using Python and Flask that analyzes resumes against job requirements and calculates ATS scores.

## Features
- ATS Score Analysis
- Resume Skill Extraction
- Missing Skill Detection
- AI Suggestions
- Premium Recruiter Dashboard
- SQL Server Database Integration
- Resume History Tracking

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQL Server
- pyodbc
- pdfplumber
- NLP Skill Matching
